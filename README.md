## Project Description
This project is a fully functional interactive To-Do List application built using JavaScript DOM manipulation.

The goal was to practice selecting elements, handling user events, and dynamically updating the UI based on user actions. The application allows users to add, delete, filter, and manage tasks efficiently.

## Features
- ✅ Add tasks using input field and submit button  
- ✅ Prevent empty tasks from being added  
- ✅ Toggle tasks as completed (with strikethrough styling)  
- ✅ Delete individual tasks  
- ✅ Filter tasks (All, Active, Completed)  
- ✅ Display number of remaining tasks  
- ✅ Clear all completed tasks  
- ⭐ Edit tasks on double-click (Bonus feature)
